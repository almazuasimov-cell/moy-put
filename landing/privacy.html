Политика конфиденциальности

Приложение «Мой путь» (AI Voice Diary)
Версия 1.0 от 4 августа 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности разработана в соответствии с Федеральным законом РФ № 152-ФЗ «О персональных данных» и определяет порядок обработки и защиты персональных данных пользователей приложения «Мой путь».

Оператор персональных данных: ИП Аюпов А.Р. (будет уточнено при регистрации в РКН).

2. Какие данные мы собираем

  • Номер телефона — для авторизации в приложении
  • Имя — для персонализации
  • Голосовые записи (аудиофайлы) — биометрические персональные данные. Собираются только при явном согласии пользователя
  • Текстовые расшифровки голосовых записей
  • Результаты AI-анализа: настроение, теги, темы, саммари, вопросы для размышления

3. Цели обработки данных

  • Распознавание речи с помощью OpenAI Whisper API
  • AI-анализ записей с помощью DeepSeek API
  • Генерация автобиографии на основе записей пользователя
  • Предоставление статистики (график настроения, теги, streak)
  • AI-поиск по дневниковым записям
  • Улучшение качества сервиса

4. Хранение данных

  • Все данные хранятся на серверах, расположенных на территории Российской Федерации
  • Аудиофайлы хранятся в S3-совместимом облачном хранилище (РФ) в течение 1 года, после чего автоматически удаляются
  • Текстовые данные (расшифровки, результаты анализа, биография) хранятся до момента удаления аккаунта пользователем
  • Пароли хранятся в хешированном виде (bcrypt)

5. Передача данных третьим лицам

  • OpenAI (Whisper API) — аудиофайлы передаются для распознавания речи. Серверы OpenAI могут находиться за пределами РФ. Передача осуществляется только с вашего явного согласия
  • DeepSeek API — тексты записей передаются для AI-анализа
  • Мы не передаём ваши данные рекламным сетям, маркетинговым компаниям и не продаём их третьим лицам

6. Ваши права (согласно 152-ФЗ)

Вы имеете право:

  • Получить информацию о том, какие данные мы храним (обратитесь в поддержку)
  • Потребовать исправления неточных персональных данных
  • Потребовать полного удаления всех ваших данных — через функцию «Удалить аккаунт» в приложении или по запросу в поддержку
  • Отозвать согласие на обработку персональных данных (это приведёт к удалению аккаунта)

7. Безопасность

  • Все данные передаются по защищённому протоколу HTTPS
  • Доступ к данным имеют только авторизованные пользователи (JWT-токены)
  • Ведётся аудит-лог всех операций с персональными данными
  • Пароли хешируются (bcrypt) и никогда не хранятся в открытом виде

8. Срок действия согласия

Согласие на обработку персональных данных действует с момента регистрации до момента удаления аккаунта или отзыва согласия.

9. Контакты

По всем вопросам, связанным с обработкой персональных данных, обращайтесь:

  • Email: support@moyput.ru (будет активирован при запуске)
  • Telegram: @Botalmaz_bot

10. Изменения политики

Мы оставляем за собой право вносить изменения в настоящую Политику конфиденциальности. Новая версия вступает в силу с момента публикации. Рекомендуем периодически проверять эту страницу.
